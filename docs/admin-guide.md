# Slurm 集群监控 — 管理员配置手册

本手册面向**管理员**，说明「集群配置」页面（项目组、节点映射）的操作。
普通用户的日常使用（名字映射、总览、GPU 详情、排队作业、个人统计、rgtop）见
[用户使用手册](user-guide.md)。

访问地址：`http://192.168.3.102:8000/` → 顶部导航 **「集群配置」**。

---

## 一、登录与权限

「集群配置」页面需要管理员账号：

1. 打开「集群配置」，未登录时显示登录框（用户名 / 密码）。
2. 账号口令由部署方在 `.env` 中配置：

   ```env
   ADMIN_USER=<管理员用户名>
   ADMIN_PASS=<管理员口令>
   ```

   **修改后需要重启 Web 容器**（`docker restart slurm-monitor-web`）才生效。
3. 登录成功后凭据保存在当前浏览器会话中，页面右上角有 **「退出登录」**。
4. 登录状态失效（例如换了浏览器、清空缓存、服务重启后 token 失效）时，页面会重新要求登录。

> 除「集群配置」外的其他页面（总览、GPU 详情、排队作业、个人统计、名字映射）
> **不需要管理员登录**，普通用户可直接访问。

## 二、项目组

用于给用户归类，是「名字映射」里给用户多选的项目组来源。

### 新增

1. 切到 **「项目组」** 标签页。
2. 点 **「+ 新增项目组」**，填写名称，点 **「保存」**。
3. 列表显示 `#ID 名称`，ID 由系统分配、不可修改。

### 修改

- 在目标行点 **「编辑」**，改名称后保存。
- 只能改名称；ID 固定不变。已引用该 ID 的用户映射会自动跟着显示新名称。

### 删除

- 当前页面**不提供删除入口**，需要下线某个项目组请联系维护方处理。

### 与用户映射的关系

- 项目组建好后，在「名字映射」页面编辑用户时即可多选项目组。
- 用户记录里存的是**项目组 ID 的逗号分隔串**（如 `1,3`），页面展示时再翻译成名称。
- 因此**先建项目组，再配用户**，否则名字映射页的项目组下拉框是空的。

## 三、节点映射

维护「算力节点名 → IP / SSH 端口 / SSH 账号 / 密码」的对应关系。
采集器据此在每个采集周期 SSH 到节点，读取 GPU（NVML）与主机指标（CPU / 负载 / 内存）。

### 新增节点

1. 切到 **「节点映射」** 标签页。
2. 点 **「+ 新增节点」**，填写：

   | 字段 | 说明 |
   |------|------|
   | 节点名 | 必须与 Slurm 里的节点名一致，否则总览/GPU 详情/排队作业页对不上 |
   | IP | 该节点可达的管理 IP |
   | 端口 | SSH 端口，默认 22 |
   | SSH 用户 | 用于采集的账号 |
   | 密码 | 该账号的密码 |
   | 采集 | 开关；关闭后停止对该节点采集，历史数据保留 |
   | 备注 | 可选说明 |

3. 点 **「测试连接」** 先验证 SSH 是否通，再点 **「保存」**。

### 修改与删除

- 每行右侧有 **「编辑」**「删除」。
- 删除后该节点不再采集，页面上的实时数据会随快照过期而消失。
- 修改**不需要重启任何服务**：采集器每个周期都会重新读取节点表，改完下个周期即生效。

### 采集账号与默认值

- 节点未单独配置账号时，使用 `.env` 里的默认值：

  ```env
  NODE_SSH_USER=<默认 SSH 账号>
  NODE_SSH_PASSWORD=<默认密码>
  ```

- 认证持续失败时，该节点会**指数退避**（30s → 15min），避免高频重试把账号锁掉。
  排查账号后再改配置即可恢复，无需重启。

### 新增节点之后

- 节点会出现在总览、GPU 详情、排队作业等所有页面。
- 第一次采集完成后才**开始有数据**（最多等一个采集周期，默认 30 秒）。
  在此之前，rgtop 等客户端可能看到节点已列出但无数据。
- 若节点上的 GPU 进程需要关联到 Slurm 作业号，要求该节点与 Slurm 采集链路正常
  （agent 沿进程祖先链找到 `slurmstepd` 得到作业号）。

## 四、常见操作对照

| 我想…… | 去哪里 |
|--------|--------|
| 新增/改名项目组 | 集群配置 → 项目组 |
| 让某个用户显示真实姓名 | 名字映射（无需管理员） |
| 把用户归到项目组 | 名字映射（需先在集群配置建好项目组） |
| 接入一台新的算力节点 | 集群配置 → 节点映射 → 新增节点 |
| 临时停止采集某节点 | 集群配置 → 节点映射 → 编辑 → 关闭「采集」 |
| 改采集用的默认 SSH 账号 | `.env` 的 `NODE_SSH_USER` / `NODE_SSH_PASSWORD`，重启 collector |
| 改管理员账号口令 | `.env` 的 `ADMIN_USER` / `ADMIN_PASS`，重启 web |

---

## 五、注意事项

- **`.env` 整数字段不允许行内注释**，注释必须单独占一行（详见 [issues.md #002](issues.md)）。
- 修改 `.env` 后需要重启对应容器；只改页面上的项目组/节点映射则**不需要重启**。
- 节点名一旦被改动，历史数据仍挂在旧节点名下，新名字需要重新采集才有数据。
- 采集账号只需读取权限；不需要给使用者开节点 SSH 权限，他们通过 Web 或 rgtop HTTP 后端读取即可。
